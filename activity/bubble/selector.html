List out the different ways to select an item.

You can select items using Universal selectors (*).

What is the difference between an ID and a Class?

An ID selector is unique and can only be used on one single element per page.

What is the difference between a SPAN tag and a DIV tag?

A DIV is a block-level element, meaning it starts on a new line and takes up the full width available.

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A DIV is a generic container with no semantic meaning.

What are the different ways to select a color?

Colors can be selected using predefined Color Names, Hexadecimal, RGB/RGBA, and HSL/HSLA values.
